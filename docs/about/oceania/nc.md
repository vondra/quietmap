## Roads

No open traffic counts; roads use OSM class defaults. Motorways, trunks, primaries and their ramps are scaled by 0.712. No vehicles-per-kilometre figure is available for New Caledonia, so the factor is derived from population density, a weaker proxy.

| OSM class | Default vehicles per day |
|---|---:|
| Motorway | 30,000 × 0.712 = 21,360 |
| Trunk | 15,000 × 0.712 = 10,680 |
| Primary | 9,000 × 0.712 = 6,408 |
| Secondary | 3,000 |
| Tertiary | 800 |
| Residential | 500 |
| Unclassified | 1,340 |
| Service | 250 |
| Track | 5 |

Where buildings are mapped, residential, living, service and unclassified streets are instead estimated from the buildings they serve.

## Railways

New Caledonia has no railway.

## Industry

Power plants: Global Energy Monitor, operating plants only, where OSM maps an industrial area at the site. Nickel smelters and mines are OSM industrial areas with a type inferred from name and tags.
