## Roads

No open traffic counts; roads use OSM class defaults. Motorways, trunks, primaries and their ramps are scaled by 0.783 (registered vehicles per road kilometre relative to Germany).

| OSM class | Default vehicles per day |
|---|---:|
| Motorway | 30,000 × 0.783 = 23,490 |
| Trunk | 15,000 × 0.783 = 11,745 |
| Primary | 9,000 × 0.783 = 7,047 |
| Secondary | 3,000 |
| Tertiary | 800 |
| Residential | 500 |
| Unclassified | 1,340 |
| Service | 250 |
| Track | 5 |

Where buildings are mapped, residential, living, service and unclassified streets are instead estimated from the buildings they serve.

## Railways

Papua New Guinea has no railway.
