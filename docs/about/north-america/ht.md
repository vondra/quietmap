## Roads

No open traffic counts; roads use OSM class defaults. Motorways, trunks, primaries and their ramps are scaled by 1.298. No vehicles-per-kilometre figure is available for Haiti, so the factor is derived from population density, a weaker proxy.

| OSM class | Default vehicles per day |
|---|---:|
| Motorway | 30,000 × 1.298 = 38,940 |
| Trunk | 15,000 × 1.298 = 19,470 |
| Primary | 9,000 × 1.298 = 11,682 |
| Secondary | 3,000 |
| Tertiary | 800 |
| Residential | 500 |
| Unclassified | 1,340 |
| Service | 250 |
| Track | 5 |

Where buildings are mapped, residential, living, service and unclassified streets are instead estimated from the buildings they serve.

## Railways

No operating railway. Any stretch that OSM still maps as a working railway takes the class default of 80 passenger and 20 freight trains per day.
